# Examples

The examples use small synthetic inputs and the installed public `moduport`
package. They are not research validation cases.

```bash
python examples/single_storey_static.py
python examples/multistorey_static_modal.py
```

`single_storey_static.py` demonstrates a mixed H/V modular layout, static
analysis, global storey response, strain energy, and representative horizontal
and vertical inter-module connection forces. `multistorey_static_modal.py`
demonstrates a three-storey model, two static load cases, frequencies, periods,
and modal classifications.
