# واجهة ModuPort العربية

ModuPort محلّل ميكانيكي بالعناصر الفائقة لتحليل وفرز تخطيطات المنشآت المعيارية الإطارية متعددة الطوابق. توفر الواجهة التحليل الساكن والنمطي لنموذج واحد، ومحرر مسقط 50 × 50، وتعداد تخطيطات الوحدات H/V الممكنة، واستكشاف KX–KY وجبهة Pareto وتخطيط الصلابة المتوازنة.

## التشغيل

```bash
python -m pip install -e ".[ui]"
python -m streamlit run web/streamlit_app.py
```

اختر « العربية » من الشريط الجانبي. يغيّر اختيار اللغة العرض فقط، ولا يغيّر المدخلات الإنشائية أو المسقط المرسوم أو النتائج العددية أو دلالة البيانات المصدّرة. يبقى نظام الوحدات mm–N، وتبقى الرموز E وG وIy وIz وKX وKY وHz كما هي. راجع ملف [README الإنجليزي](../README.md) لتفاصيل API ونطاق الاستخدام والقيود والترخيص.
