# ModuPort: краткое описание на русском языке

ModuPort — механический решатель на основе суперэлементов для расчёта и скрининга компоновок многоэтажных каркасных модульных зданий. Интерфейс поддерживает статический и модальный расчёт одной модели, редактор пятна застройки 50 × 50, перечисление допустимых H/V-компоновок, а также просмотр KX–KY, фронта Парето и компоновки со сбалансированной жёсткостью.

## Запуск

```bash
python -m pip install -e ".[ui]"
python -m streamlit run web/streamlit_app.py
```

Выберите « Русский » на боковой панели. Язык влияет только на отображение и не меняет исходные данные, пятно застройки, численные результаты или смысл экспортируемых данных. Сохраняются единицы mm–N и обозначения E, G, Iy, Iz, KX, KY и Hz. API, область применимости, ограничения и лицензирование описаны в основном [README на английском языке](../README.md).
